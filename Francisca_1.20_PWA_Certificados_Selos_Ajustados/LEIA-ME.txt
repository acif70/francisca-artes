FRANCISCA 1.20 — PWA LOCAL-FIRST

Arquitetura oficial: PWA local-first.

COMO PUBLICAR
1. Envie todo o conteúdo desta pasta para um repositório GitHub.
2. Conecte o repositório ao Cloudflare Pages.
3. Não é necessário comando de build: este pacote é um site estático.
4. Diretório de saída/publicação: a raiz desta pasta.

COMO USAR
- Abra a URL publicada no Chrome ou Edge.
- Após o primeiro carregamento, a aplicação pode funcionar offline.
- O navegador poderá oferecer a opção de instalar a Francisca como aplicativo.

DADOS
- Obras e preferências desta versão permanecem locais no navegador/dispositivo.
- A hospedagem publica o aplicativo, não o acervo pessoal do artista.
- Não limpe os dados do site sem antes ter um backup quando esse recurso estiver disponível.

IMPORTANTE
- Service Workers exigem HTTPS ou localhost. Por isso, abrir index.html diretamente pelo explorador de arquivos não ativa toda a experiência PWA.
